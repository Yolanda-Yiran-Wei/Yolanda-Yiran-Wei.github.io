Part 1: Fun with Filters

Part 1.1: Convolutions from Scratch

I implemented convolution using NumPy and matrix multiplication, as shown in the code below. The first function uses 4 for-loops, and it computes the value of each pixel in the output image by multiplying the filter and the input image pixel by pixel and summing the results. The second function uses 2 for-loops, and it computes the values of the output image by doing matrix multiplication between the filter and the padded input image.

Before implementing the convolution, I padded the image with zeros around the edges to handle the boundaries of the image. I also flipped the filter, so that the function does convolution instead of correlation. The 2-loop convolution is faster than the 4-loop convolution because matrix multiplication is more efficient than multiplying each pixel by each element of the filter. I compared my convolution functions with the scipy.signal.convolve2d function, and they produce the same results.

def convolve(img, filter): 
    img_height = img.shape[0] + 2
    img_width = img.shape[1] + 2
    
    # padding w zero fill values
    padded = np.zeros((img_height, img_width))
    padded[1:img_height-1, 1:img_width-1] = img
    
    fil_height = filter.shape[0]
    fil_width = filter.shape[1]
    
    filter = np.flip(filter)
    
    result = np.zeros((img_height-fil_height+1, img_width-fil_width+1))
    
    for h1 in range(img_height-fil_height+1):
        for w1 in range(img_width-fil_width+1):
            for h2 in range(fil_height):
                for w2 in range(fil_width):
                    result[h1, w1] += filter[h2, w2] * padded[h1+h2, w1+w2]
    
    return result
        
def convolve_2(img, filter):
    # same variables and padding as above
    result = np.zeros((img.shape[0], img.shape[1]))
        
    for h1 in range(img_height):
        for w1 in range(img_width):
            result[h1, w1] = filter @ padded[h1:h1+fil_height, w1:w1+fil_width]
    
    return result

Part 1.2: Finite Difference Operator

I convolved the cameraman image with the finite difference operators Dx and Dy. I computed the gradient magnitude of the image by np.sqrt(result_d_x ** 2 + result_d_y ** 2). I then binarized the gradient magnitude image to create an edge map by setting pixels greater than a threshold to white and the other pixels to black. If the threshold is too low, the edge map will be too noisy. If the threshold is too high, the edge map will be too sparse. I chose a threshold of 70 for the edge map.

Part 1.3: Derivative of Gaussian (DoG) Filter

I created a 2D Gaussian filter by using cv2.getGaussianKernel() to create a 1D kernel and then taking the outer product with its transpose. I convolved the image with the Gaussian filter to create a blurred image. I then convolved the blurred image with the finite difference operators Dx and Dy to create the gradient magnitude image. This produces an edge image with less noise, but the thresholds need to be adjusted. I also did the same thing with a single convolution by creating a Derivative of Gaussian (DoG) filters.

Part 2: Fun with Frequencies

Part 2.1: Image Sharpening

In this part, I implemented the unsharp mask filter. I blurred the image with a Gaussian filter to retain the low frequencies. Then, I subtracted the blurred image from the original image to get the high frequencies. I added a multiple of the high frequencies to the original image to sharpen the image. 

blurred = scipy.signal.convolve2d(img, gaussian)
details = img - blurred          # high frequencies
sharpened = img + alpha * details

Part 2.2: Hybrid Images

I aligned two images by choosing points like eyes or object edges. I implemented hybrid images by filtering image 1 with a Gaussian filter to get the low frequencies and an impulse filter subtracted by a Gaussian filter for image 2 to get the high frequencies. I combined the low and high frequencies of the two images to get the hybrid image. I used a kernel size of 31 and sigma of 5 and 6 for cutoff frequencies respectively for the filters.

Part 2.4: Multiresolution Blending

To blend two images together, I created a mask by applying the Gaussian stack to a step function (...0, 0, 1, 1, ...). I used the Laplacian stack of one image and multiplied it by the mask (and the Laplacian stack of the other image and multiplied it by 1 - mask) to blend the images. I then reconstructed the image by adding the Laplacian stacks of these together.
